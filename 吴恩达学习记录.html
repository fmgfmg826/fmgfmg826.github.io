机器学习全景笔记：从线性回归到强化学习

本文是基于吴恩达 Machine Learning Specialization 课程的深度学习笔记。内容涵盖监督学习（回归与分类）、神经网络与深度学习、以及无监督学习与强化学习的核心概念与工程实践。

第一部分：监督学习 (Supervised Learning)

监督学习的核心是通过输入 x 和对应的正确输出 y，训练算法来预测未知数据的输出。

1. 核心算法分类

  • 回归 (Regression)：预测连续的数值输出。
    • 经典案例：根据面积预测房价。
    • 算法：线性回归 (Linear Regression)。
  • 分类 (Classification)：预测离散的类别标签。
    • 经典案例：乳腺癌检测（良性/恶性）、垃圾邮件分类。
    • 算法：逻辑回归 (Logistic Regression)。

2. 线性回归 (Linear Regression)

  • 模型：f(x) = w * x + b
  • 代价函数 (Cost Function)：均方误差 (MSE)，用于衡量预测值与真实值的差距。形象化理解为一个“碗”形曲面。
    • 目标：找到 w, b 使得 J(w,b) 最小。
  • 梯度下降 (Gradient Descent)：
    • 一种迭代优化算法，沿着代价函数下降最快的方向更新参数。
    • 关键点：w 和 b 必须同步更新 (simultaneous update)。
    • 学习率 (Alpha)：控制步长。过小导致收敛慢，过大可能导致发散。

3. 实用技巧

  • 向量化 (Vectorization)：利用 NumPy 进行矩阵运算，代替显式的 For 循环，大幅利用并行计算提升速度。
  • 特征缩放 (Feature Scaling)：
    • 问题：如果特征范围差异大（如房价 vs 房间数），代价函数的等高线呈椭圆，导致梯度下降路径曲折。
    • 解法：使用 Z-score 标准化或均值归一化，使特征范围相近（如 -1 到 1），加速收敛。

4. 逻辑回归 (Logistic Regression)

虽然名字叫“回归”，但它是二分类算法。

  • Sigmoid 函数：将输出压缩到 (0, 1) 之间，表示概率。
    • 公式：g(z) = 1 / (1 + e^(-z))
  • 决策边界 (Decision Boundary)：如 g(z) >= 0.5 预测为 1，否则为 0。
  • 损失函数：不能用均方误差（因为是非凸函数），需使用对数损失 (Log Loss)。

5. 过拟合与正则化 (Regularization)

  • 过拟合 (Overfitting/High Variance)：模型在训练集表现极好，但在新数据上表现差（泛化能力弱）。
  • 欠拟合 (Underfitting/High Bias)：模型太简单，无法捕捉数据规律。
  • 解决方案：
    1. 增加训练数据。
    2. 特征选择（减少特征数量）。
    3. 正则化：在代价函数中引入惩罚项 lambda。
      • Lambda (λ) 的影响：
        • λ 过大 -> 欠拟合（参数被压缩接近 0）。
        • λ 过小 -> 过拟合（几乎无约束）。

第二部分：深度学习 (Deep Learning)

1. 神经网络基础

  • 结构：输入层 -> 隐藏层 (Hidden Layers) -> 输出层。
  • 本质：每一层神经元可以看作是一个逻辑回归单元，通过组合学习更复杂的特征。
  • 前向传播 (Forward Propagation)：数据从输入层流向输出层的过程。
  • 实现细节：
    • 使用矩阵乘法高效计算：Z = np.matmul(A_in, W) + B。
    • TensorFlow/Keras 是主流框架。

2. 激活函数 (Activation Functions)

  • Hidden Layer 选择：
    • ReLU (g(z) = max(0, z))：最常用，计算快，且在正区间无梯度消失问题。
  • Output Layer 选择：
    • 二分类问题：Sigmoid。
    • 多分类问题：Softmax。
    • 回归问题（正数）：ReLU。
    • 回归问题（任意值）：Linear。

3. 多分类与 Softmax

  • Softmax：输出属于每个类别的概率，且概率之和为 1。
  • 数值稳定性优化：在 TensorFlow 中，推荐使用 from_logits=True。这会让计算包含在损失函数内部，避免浮点数精度溢出问题。

4. 机器学习项目诊断 (Diagnostics)

如何改进模型？不要盲目尝试，要看指标。

  • 数据集划分：
    • Training Set (60%)：训练参数。
    • Cross Validation Set (20%)：调参（选择模型架构、多项式次数、正则化系数），计算 Jcv。
    • Test Set (20%)：评估最终模型的泛化能力。
  • 偏差 vs 方差 (Bias vs Variance)：
    • Jtrain 高，Jcv 高 -> 高偏差 (欠拟合) -> 对策：增加网络复杂度、减少正则化、增加特征。
    • Jtrain 低，Jcv 高 -> 高方差 (过拟合) -> 对策：增加数据、增大正则化、减小网络规模。
  • 误差分析：人工检查模型出错的样本，寻找规律（如拼写错误、特定背景噪音）。

5. 决策树与集成学习 (Tree Ensembles)

  • 基本概念：
    • 通过信息增益 (Information Gain) 选择分裂特征，核心是使得分裂后的子节点纯度 (Purity) 变高（熵 Entropy 降低）。
    • 独热编码 (One-hot Encoding)：处理无序的分类特征。
  • 高级模型：
    • 随机森林 (Random Forest)：多棵树并行投票，通过“有放回采样”和“特征随机子集”增强健壮性。
    • XGBoost：目前竞赛最强模型之一。基于 Boosting 思想，后续的树专门修正前序树预测错误的样本。内置正则化，效率极高。
  • 选型建议：
    • 表格数据 (Tabular Data)：首选 XGBoost/决策树。
    • 非结构化数据 (图像/音频/文本)：首选神经网络。

第三部分：无监督学习与强化学习

1. 聚类 (Clustering)

  • K-Means 算法：
    1. 随机初始化 K 个质心。
    2. 分配：将每个样本分配给最近的质心。
    3. 移动：重新计算每个簇的平均值作为新质心。
    4. 重复直到收敛。
  • 肘部法则 (Elbow Method)：通过绘制代价函数随 K 变化的曲线，选择“手肘”点作为最佳聚类数。

2. 异常检测 (Anomaly Detection)

  • 场景：欺诈检测、工业质检。特点是正样本（异常）极少。
  • 方法：使用高斯分布 (Gaussian Distribution) 建模。如果某个样本的概率 p(x) < epsilon，则判定为异常。

3. 推荐系统 (Recommender Systems)

  • 协同过滤 (Collaborative Filtering)：
    • 利用用户对物品的打分矩阵。算法同时学习“用户偏好特征”和“物品特征”。
    • 均值归一化：解决新用户没有评分数据的问题。
  • 基于内容的过滤：利用物品本身的属性（如电影流派、演员）进行推荐。
  • PCA (主成分分析)：用于降维和数据可视化，保留数据方差最大的方向。

4. 强化学习 (Reinforcement Learning)

核心是通过与环境交互，学习最大化长期回报 (Return) 的策略。

  • 关键要素：
    • State (状态 s), Action (动作 a), Reward (奖励 r), Discount factor (折扣因子 γ)。
  • 马尔可夫决策过程 (MDP)：未来只取决于当前状态，与过去无关。
  • 贝尔曼方程 (Bellman Equation)： Q(s, a) = R(s) + gamma * max(Q(s', a'))
    • 当前的价值 = 即时奖励 + 折扣后的未来最大价值。
  • DQN (Deep Q-Network)：
    • 使用神经网络拟合 Q 函数：输入状态 s，输出所有动作的 Q 值。
    • Epsilon-Greedy 策略：
      • 以 1 − ϵ 的概率选最优动作 (Exploitation)。
      • 以 ϵ 的概率随机探索 (Exploration)。
    • 经验回放 (Replay Buffer)：存储 (s, a, r, s') 元组，随机采样训练，打破数据相关性，使训练更稳定。

总结： 机器学习不仅是数学推导，更是工程实践。从选择模型、数据清洗、特征工程到误差分析，构成了一个完整的迭代闭环。
